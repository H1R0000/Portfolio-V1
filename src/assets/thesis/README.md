# Thesis screenshots

Place your thesis images in `public/images` as PNG, JPG, JPEG, WebP, or AVIF files.
Use numbered names such as `Agila-1.png`, `Agila-2.png`, and `Agila-3.png` to set the gallery order.

Add the image paths to the thesis project's `images` list in `src/components/Projects/Projects.jsx`.
The first image becomes the project cover.

Run `npm run build` and republish the website after adding images.
