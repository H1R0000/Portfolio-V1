# Thesis screenshots

Place your thesis images in this folder as PNG, JPG, JPEG, WebP, or AVIF files (lowercase extensions).
Use names such as `01-login.png`, `02-attendance.png`, and `03-location.png` to set the gallery order.

The first image becomes the project cover. The gallery appears automatically when images are present;
otherwise the thesis card displays a neutral “Screenshots coming soon” panel without broken images or inactive buttons.

Run `npm run build` and republish the website after adding images.
